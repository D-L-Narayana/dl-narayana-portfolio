# D L NARAYANA — Portfolio

Animated hero: hand-drawn "Hello" stroke intro → wavy scroll-up exit → elastic letter-by-letter name entrance ("D L NARAYANA") over a Three.js particle-wave + wireframe torus-knot background.

Stack: vanilla HTML/CSS/JS, GSAP 3 (timelines, elastic/stagger), Three.js r128 (WebGL background). All libraries and fonts vendored — zero runtime CDN dependencies.

Run locally: any static server, e.g. `python3 -m http.server 8090` then open http://localhost:8090
